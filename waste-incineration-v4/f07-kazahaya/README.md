- 呼び名：PM-NAVI「燃焼火格子」「誘引通風機」／メーカー報告書「No.1 ストーカ（燃焼段）」「No.1 IDF（誘引送風機）」／日報・メモ「IDF」「誘引ファン」「3SH」「バグ」。
