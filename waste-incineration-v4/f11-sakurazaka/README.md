## (3) 資料どうしの書き方の違い
- **呼び名**
  - 計画・台帳は機器名、工程表はまとまりの名前（例「送風機・誘引通風機 点検」）です。
  - 手書きの日報は略語です（IDF、FDF、BF、BFP、SB、CV、クリンカー）。
  - CSV は契約の件名、手配表は品名と図番です。
- **号炉**：台帳は「1号炉」、計画は「1」。手書き日報の工事名は「定期整備」だけで号炉を書かず、作業の行に「1号」「2号」と書くこともありません（どの炉かは日付と工程表で分かる）。
- **日付**

  - 報告書の日付は工期の終わり近く、CSV は負担行為日と支出命令日です。
  - 工事の 1 日延長は、工程表の実績・日報（清書）の特記・報告書のサマリーに同じ内容で出ます。
- **金額**

  - CSV では同じ契約が負担行為と支出命令の両方のブロックに出ます。
