## (3) 資料どうしの書き方の違い
- 機器番号：計画・台帳は市番号（2B-002）。m1 の報告書は図書番号（KR-201 など、更新前の年度は竣工時の F-202 など）。g1 の報告書は市番号を併記。日報・工程表は番号なし。
- 呼び名：散気装置＝m1 報告書「散気管」、g1「散気ノズル」。誘引通風機＝m1「誘引送風機」。定量給じん機＝m1「給塵スクリュー」。バグフィルタ＝m1「バグフィルター」。流動床炉本体＝m1「焼却炉本体」。廃熱ボイラ＝m1「ボイラ」。
- 粒度：計画は機器 1 行・年度 1 記号。工程表は作業のまとまり（例「砂循環設備 点検」に 5 機器）。日報は日ごとの作業。m1 報告書の一覧表は設備ごとの台数。
- 日付：計画・台帳は和暦の年度、工程表は月/日、日報は和暦の年月日、CSV は西暦 yyyy/mm/dd。
- 追加補修：工程表は「（追加）」の行（予定なし）、日報は特記事項に発見の記録、報告書の結果表は「補修（追加）」、発注台帳は定期整備業務委託の「（変更）」の行。H22 の 1号炉耐火物補修は見本のとおり。
- 遅れ：工程表の予定と実績のずれ（多い年は H19・H21・H25・H26・H27）。日報の特記事項に「完了は m/d の見込み」。
