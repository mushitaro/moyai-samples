### (3) 資料どうしの書き方の違い
- 同じ機器の名前：台帳 k3「誘引通風機」／k2 台帳「誘引送風機」／報告書・日報「IDF」。「バグフィルタ」／「ろ過式集じん器」／「BF」。「湿式洗煙塔」／「洗煙塔」。「触媒反応塔」／「脱硝反応塔」。
- 同じ作業の粒度：工程表は班ごとにまとめた作業（「スートブロワ SB-2・SB-5 他 分解整備」）、日報は日ごとの部分作業、報告書 r1 と r2 新は機器 1 台ずつ、r2 旧は設備ごとの文章。
- 日付：工程表の予定と実績のずれ（約 15% の作業で 1〜2 日の遅れ）。報告書 r2 新の「工程実績」と日報の日付は実績どおり、m1 工程表は予定のまま。
- 追加作業（約 1 割の定修）：m2 工程表は赤字の行、日報は「【追加】」、報告書は変更契約の欄、CSV は変更後の契約額。m1 工程表には出ない。
- 和暦と西暦：市の計画・旧台帳・旧 CSV は和暦、メーカーの新様式・新台帳・新 CSV は西暦。
- 灰溶融の休止：台帳「H25.10 休止」、旧 CSV「灰溶融設備休止措置業務委託」、計画「休止（H25.10〜）」。
- 直営の作業：d1・d2 の日報にだけ出る。部品は発注控と、3 万円以上なら CSV にも出る（同じ買い物。二重に数えない）。
