# 【架空】あさぎ市清掃工場（F01）本作り — わざと入れた揺れと食い違い

対象期間 1997–2026 年度（2026 年度は 2026-11-13 時点）。資料は `files/`（フラット）、正解は `answer/files/<stem>.json` と `answer/world.json`、生成器と検査は `gen/` にある。

- 作り直し：`cd gen && python3 run_full.py`
- 検査：`python3 check.py`

ここに挙げたもの以外の食い違いは誤りとして扱う。汚さは 3 種類に分けた。

## (3) 資料どうしの書き方の違い（同じ作業を別の書き方で）
| 違い | 例 |
|---|---|
| 機器の呼び名 | 台帳 H20「No.1 ボイラ給水ポンプA」／台帳 R1・計画「ボイラ給水ポンプA」（号炉は別の列）／H20 台帳・a2 計画の「１号押込送風機」「押込送風機　」。world.json の equipment.names に資料ごとの呼び名を入れた |
| 機器の指し方 | 平成 30 年度までの報告書はメーカー機器番号（F-201）、令和元年度以降は機器コード（2E-001）、a2 計画は管理No（通-201） |
| 粒度 | 工程表は 1 行に 2〜3 台をまとめることがある（「〜（点検）」「ほか n 台」）。日報は工程の行ごと。報告書は機器 1 台ごと。発注台帳は契約ごと（定修 1 行に数十台の作業） |
| 日付 | 工程表は計画の日付。日報は作業した日だけ（日曜は休工）。報告書の工期は契約の工期。補修工事は、定修の工程表の「別契約」行と自分の工程表の施工期間が同じ。2025 年度 1号炉 BF ろ布交換は、工程表の予定 6/24 に対し実績 6/26（改訂欄・日報 6/18・6/24・6/26・報告書） |

| 和暦と西暦 | 手書き・m1・m2・c1・旧CSV・r1 は和暦、新CSV は西暦、星取表の年度は「元」「2」…の数字 |

| 計画と実績 | 星取表の過去の計画行は当初計画なので、実績と年度・区分がずれる行がある（例：2号炉押込送風機 R2 計画△→実績なし、R7 計画○→実績△〈補修工事〉）。H25 版・R1 版・R3 版・R5 版の計画は、その後の実績と一致しない（作成時点の情報だけで作ったため） |

## 作り方の覚え書き
- 版：Python 3.13.18、openpyxl 3.1.5、python-docx 1.2.0、Pillow 12.3.0、LibreOffice 24.2.7.2（`-env:UserInstallation=file:///tmp/lo_F01`）、poppler（pdftoppm・pdftotext）。
- 固定しているもの
  - 「今日」は 2026-11-13 に固定。
  - 乱数は、機器タグ・年度などの md5 から作った `random.Random` だけを使う。
  - xlsx の文書の日時と zip 内の時刻は 2026-11-13 9:00 に固定。
  - 同じ命令を 2 回実行し、PDF 以外（xlsx・csv・jpg・正解 json）が同じになることを確かめた。PDF は LibreOffice が作成日時を入れるため、バイト列は毎回変わる（本文は同じ）。
- 順序は運営者の条件 §4.3 のとおり：機器（445 台）→ 状態と履歴 → 年度別の工事 → 契約 → 工程（タスク）→ 日報 → 報告書・発注。
  - 日報の行は、その日に動いている工程のタスクから作る。
  - 2011・2025 年度は承認済みの見本の工程・日報の行をそのまま使った。
- 手書きのスキャン：帳票の PDF の頁を画像にして加工した。ただし帳票に記入された文字は活字のまま（手書きの文字は丸・チェック・短い書き込みだけ）。
- 正解の書き方
  - 日付は ISO 形式（和暦→西暦の変換）。
  - manDays は人・時間を 8 で割った人日。manDaysText は帳票に書いてある工数の文字そのまま。
  - 星取表の marks は西暦 4 桁ごとの記号、a1・a2 の marks は金額。
- 中長期計画の行
  - 機器ごとの状態（健全度）、履歴、整備周期の幅から作った。
  - 重要度 C は直近の 1 回、B は 2 回までしか置かない。
  - 同型の並列機は年に数台ずつ回す。両炉の同じ機器が同じ年に並べば、2号炉を 1 年ずらす。
  - 年度の上限を超える年は、重要度の低いものから翌年へ送る。

## 正解の形（2026-11-15 に物差しの形 moyai.sample-world/0 へそろえた）
- `answer/world.json`：次の欄を持つ。
  - schema・facility・profile・maker.today
  - assets（445 台）
  - works：実績、R8 の施工中、予定 planned、実施されなかった予定 not_done、法令点検 LGxx-年度
  - links：星取表・計画表の印は year つき、日報は day つき、how は direct・annual・bundle
  - errata：印の抜け 1 件
  - files
- 今までの world.json にあって新しい形に無い欄は `answer/world.extra.json` に移した：どこにも書いていない作業、ほかの計画の欠け、法令点検、旧形式の結び、印の当て方の説明（notes）。
- 変換器は `gen/to_v2.py`。`gen/_answer_v1/` の旧正解から answer/ だけを書く。files/ は読みも書きもしない。
- 変換の前に files/ のハッシュを `gen/files_sha256_before_v2.txt` に控えた。check.py は files/ がこれと一致することも確かめる。
